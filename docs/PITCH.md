## 演示 Checklist

- [ ] 笔记本：`npm run build && npm start`（或 `docker compose up`），浏览器打开 `http://localhost:8787/demo`
- [ ] 手机与笔记本连同一 Wi-Fi；Lobby 二维码会自动使用局域网地址
- [ ] 需要麦克风的手机：用 `npm run dev:https` 提供 HTTPS（自签证书，点“继续访问”）
- [ ] 断网备用：`/demo` 全部本地运行（规则引擎 + 预置 Rodin 模型）
- [ ] 观众大屏：另开 `/watch/房间号`

## 评委可能的问题

- **和 ChatGPT 语音陪练有什么区别？** 我们练的是“让对方做对一件事”的交际能力，结果可验证（队友拿没拿对），且错误可以精确归因到视角、指代或歧义。
- **为什么不全用大模型？** 现场网络不可控、延迟高；规则引擎即时、可测试、零成本。大模型只在规则无法解析时兜底，并负责个性化改写。
- **Rodin 是核心还是装饰？** 物品就是游戏的词汇表：兴趣决定物品，物品决定要说的英语；Object Studio 让玩家把自己的东西放进关卡。
