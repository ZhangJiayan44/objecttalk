# 产品设计与市场策略 · ObjectTalk

> 这份文档回答三个问题：我们和已经上架 Steam 的 Noun Town 有什么不同；每个设计为什么这样做；怎么让更多人来玩、留下来。

## 1. 竞品对照

| | **Noun Town**（Steam / Meta Quest） | **ObjectTalk** |
|---|---|---|
| 形态 | 单人 VR / PC，$19.99 买断，不支持手机 | **浏览器即玩**，扫码进房间，手机、平板、电脑都能用，免安装 |
| 学什么 | 1000+ 名词与短语，指物认词，间隔重复 | **说完整的句子把事办成**：方位（your left / closer to you）、点单（数量、复数、大小杯、礼貌用语）、问路、找东西 |
| 社交 | 官网写明 **“no chat or social component”**（桌面版没有聊天或社交功能） | **实时双人、信息差协作**：一个人有信息，一个人在 3D 世界里动手；说不清，队友就做错 |
| AI | 语音识别给发音打分 | **LLM 工具调用 Agent 当搭档**（能独自玩），带接地工具与护栏，推理过程可见；赛后逐句点评、改写和 CEFR 估计 |
| 内容 | 美术团队手工制作的一座小镇 | **Rodin 生成内容**：149 个 Rodin 模型；Scene Agent 一句主题生成整关；玩家拍照把自己的东西变进游戏 |
| 面向 | 全球多语种学习者 | 中文母语的 A2–B1 英语学习者（初高中、大学），带 **中文求助**、中英词卡 |

**一句话定位**：Noun Town 教你认“这是什么”；ObjectTalk 逼你说清楚“是哪一个、在哪、要几个、怎么走”，而且说给一个真人听。

### 我们的五个差异化武器

1. **信息差双人协作**（*Keep Talking and Nobody Explodes* 的社交玩法）：沟通本身就是玩法，结果可验证（队友有没有端对奶茶、走到医院），不是“陪聊”。
2. **零门槛**：扫码即玩，不用下载，不用注册，不需要 VR。课堂、展位、宿舍都能马上开一局。
3. **为中国学习者设计**：中文求助（卡住时说中文，私下拿到英文，再自己说出来）、中英词卡、夜市里的饺子和奶茶，都是他们每天生活里的场景。
4. **AI 不只是 NPC**：搭档是有工具、有护栏的 Agent；教练逐句指出“north 对问路的人没有意义”这类具体问题，并给出改写。
5. **无限内容**：Rodin + Scene Agent 让一个新场景只需要一条命令；Object Studio 让玩家的东西进入游戏，生成的内容是个人化的。

## 2. 关键设计决策

### 2.1 中文求助（卡住了怎么办）

**问题**：学习者不会说某个词时会沉默，硬逼也说不出来，体验就此中断。

**设计**：

- **触发**：按 `H`，或点“中文求助”，打字或按住说中文。在普通聊天框里打中文，也会自动走求助通道。
- **私密**：英文只出现在本人的卡片上并朗读一遍，队友永远看不到中文。服务器拦截所有中文聊天，保证“对方只听到英文”。
- **自己说出口**：卡片写着“按住空格，自己说出来”。系统检测你之后是否真的说了，回顾里标为 *you said it ✓* 或 *not said yet*。
- **代价轻、有上限**：每局第一次免费（求助本身也是一种能力），之后每次 −4 分，每局最多 8 次。用了求助的句子不计入 CEFR 估计。
- **闭环学习**：赛后的“Words you borrowed”卡片列出每句借来的英文，可以点读；同时进入词本，在 Progress 页面用翻卡复习，借得多的排在前面。
- **离线也能用**：有 LLM 时用 DeepSeek 结合当前关卡的物品翻译；没有 LLM 时用离线词表（物品中文名 + 常用方位、点单短语）兜底。

### 2.2 Object Studio：从“上传接口”变成游戏的一部分

旧版流程只到“上传图片，生成 3D”，生成完就结束了。新版是一条学习链路：

1. **拍照**（手机直接调后置相机）。
2. **AI 认物并教词**：开源多模态模型 Qwen3.6 先识别物体，给出英文名、复数、中文和一个例句，并朗读。照片不合格（多个物体、太暗、截图等）会提示怎么重拍，免得浪费 Rodin 额度。
3. **生成的 1–3 分钟变成练习时间**：页面让你跟读例句，浏览器听到后打勾。
4. **选一个地方把它带进游戏**：
   - 书桌：队友要靠你的描述找到它。
   - 卧室：它被藏起来了，第一个任务就是找它。
   - 咖啡馆：它是今日特供，第一单一定点它，点单解析器能听懂它的名字。
5. **“我的物品”**：只显示自己拍的（存在本地浏览器），在大厅里的书桌、卧室和所有点单关卡都能选用。词本里也会多一张带图片的词卡。

### 2.3 场景与内容

- **Rodin 第四波生成：73 个模型**，全部图生 3D。参考图和成品都逐一检查过正面和背面，最终全部可用。
  - 宠物 10 个
  - 夜市小吃 12 个
  - 咖啡馆新菜单 9 个
  - 场景道具 42 个（植物、车辆、球类、家电、动物等）
- **新关卡**：
  - **Pet Shop**（宠物店，tabletop 引擎）：笼子里睡觉的小狗小猫、会游的鱼缸、鹦鹉架、乌龟池。
  - **Night Market**（夜市，order 引擎）：六家店铺组成可行走的灯笼街。向导掌握地图与秘密清单，购物者前往店铺采购并回入口交付，练习问路、店名、数量、大小与 *a bowl of / a bag of / an ear of* 等量词。
- **原有场景加内容**：
  - Corner Café 菜单从 10 个扩到 19 个，菜单板只显示今天柜里有的东西。
  - Fruit Market 有了自己的露天集市：条纹遮阳棚、果箱、货车。
  - Toy Town 街上开着小汽车、出租车、公交车、货车和电动车，公园里有小狗、风筝、气球和游泳的鸭子。
  - 卧室和书房加了小猫、球、行李箱等。
- **会动、能学的场景**：动物会呼吸、左右张望；鱼和鸭子在游。准星对准任何道具都会弹出中英词卡，点一下朗读并存进词本。用这种方式把 Noun Town 的“指物认词”嵌进协作玩法里。
- **点单不爆盘**：生成点单时保证总数不超过托盘的 6 格，避免出现“正确答案端不出来”的坏局。

### 2.4 任务选择与每日挑战

- 每类关卡有 2–3 种任务主题，房主在大厅选，例如：
  - 书桌：*Which one?*（只找东西，到处是双胞胎和相似物）、*Tidy up*（只放东西）
  - 点单：*Party order*（大数量）、*Drinks run*（必有饮料，练大小杯）
  - 问路：*Long walk*（更远，转弯更多）
  - 卧室：*Hide and seek*（只藏在 under / inside / behind）
- **Daily Challenge**：同一天、同一关卡，所有房间的世界和任务完全相同，同学之间可以比分。这是留存和传播的钩子。
- 任务只调节现有引擎（任务类型、点单形态、藏匿程度），所以每个任务都能通过同一套 AI 对 AI 模拟验证：16 个模拟测试全部通过。

## 3. 增长：怎么让更多人来玩

| 渠道 | 做法 | 已有支撑 |
|---|---|---|
| **课堂** | 老师一句主题生成一关（Scene Agent），全班两两结对；Daily Challenge 当课前 5 分钟热身 | 扫码进房、AI 搭档补位、回放二维码 |
| **展位 / 社团** | 90 秒一局，大屏 `/watch` 观战，`/demo` AI 对 AI 自动循环 | Watch 页、Demo 页 |
| **社交传播** | 每日挑战分数、回放链接、“我把我的杯子做成了 3D 并藏进了卧室” | 回放二维码、Object Studio |
| **个人练习** | 没朋友在线时和 AI 搭档玩；词本复习 | AI 搭档、Word book |

**留存循环**：每日挑战（今天来） → 中文求助和词本（学到东西） → 下一局不用求助（看到进步） → Progress 曲线和 CEFR（成就感） → 拍新物品、开新主题（新鲜感）。

## 4. 下一步路线图

1. **老师端**：班级房间批量创建、一节课的数据汇总（谁求助最多、常错的介词）。
2. **语音通道**：实时语音（已有 WebRTC 链路）加服务端 ASR，弱网下更稳。
3. **更多 walksearch 场景**：把卧室引擎抽象为 `Place` 数据（详见代码梳理结论），加公园找小狗、超市找商品。
4. **难度自适应**：按 CEFR 估计自动选难度和任务。
5. **多语言**：引擎与语言解耦，下一步做中文 / 日语作为目标语。
