### 项目简介

英语口语练习的最大问题是**没有开口的理由**：AI 陪聊不在乎你说得清不清楚，对错只靠打分。
ObjectTalk 把“说清楚”变成通关条件。Guide（向导）看得到金色目标，却不能动手；
Builder（操作者）能动手，却看不到目标。两人站在桌子**两侧**，所以 Guide 的左边就是
Builder 的右边。一局 90 秒、3 个任务（找物 Find / 摆放 Place），说错了队友就会拿错。

赛后系统回放整局操作和对话，**逐句**指出哪句话为什么会被误解（比如“没说是谁的左边”
或“有两个一样的杯子”），并给出更清楚的说法。

### 功能说明

1. **六个日常场景关卡**：Cozy Study 书房（找物/摆放，练方位与视角）、Corner Café 咖啡馆（点单，练数量/复数/大小杯/礼貌用语）、Toy Town 小镇（问路，问路者在 3D 街道中行走）、Messy Bedroom 卧室（寻物，练 under / inside / on top of / behind）、以及由 Scene Agent 自动生成的 Music Room 与 Fruit Market。
2. **可行走的 3D 世界**：第一人称视角，点击后锁定鼠标、移动鼠标即转动视角（CS 式），WASD 行走带碰撞；手机端拖动转视角 + 虚拟摇杆。场景含环境光遮蔽、灯光泛光、光束与浮尘等氛围效果。
3. **双人信息差，协议层隔离**：每个关卡的秘密信息（目标、点单卡、目的地、物品位置）只发给对应一方；卧室中未打开的玩具箱内容也不会下发给寻找者。
4. **语音优先的交流方式**：按住空格说话，默认不显示对方文字（只听），可一键重听 / 单句显示 / 按 C 打开字幕、按 T 查看完整记录；1–6 快捷短语、带中文释义的短语手册，可选 WebRTC 远程语音。
5. **更聪明的 AI 搭档**：每个关卡都有基于对话状态的规则大脑（回答你真正问的问题、追问大小杯与数量、按路口执行“第二个路口右转”）；开启 Claude 后成为带接地工具与护栏的工具调用 Agent，按 G 可查看推理过程；`/demo` 可观看 AI 对 AI。
6. **赛后教练与 CEFR 评估**：逐句诊断（视角、方位词、数量与复数、地图词、介词等）与改写建议，各关卡独立技能维度，并估计本局口语水平（A1–C1）。
7. **3D 回放**：所有关卡均可回放，行走类关卡带移动轨迹，可切换双方视角。
8. **Scene Agent（Rodin 第四级）**：一句话主题 → 规划 → 参考图 → 审核 → Rodin 生成 → 优化 → 可玩性模拟 → 发布为新关卡。
9. **现场体验设计**：扫码加入、观众大屏 `/watch/房间号`、单屏演示 `/demo`（AI 对 AI，可作断网备用演示）。
