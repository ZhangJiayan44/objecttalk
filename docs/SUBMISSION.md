### 项目简介

英语口语练习的最大问题是**没有开口的理由**：AI 陪聊不在乎你说得清不清楚，对错只靠打分。
ObjectTalk 把“说清楚”变成通关条件。Guide（向导）看得到金色目标，却不能动手；
Builder（操作者）能动手，却看不到目标。两人站在桌子**两侧**，所以 Guide 的左边就是
Builder 的右边。一局 90 秒、3 个任务（找物 Find / 摆放 Place），说错了队友就会拿错。

赛后系统回放整局操作和对话，**逐句**指出哪句话为什么会被误解（比如“没说是谁的左边”
或“有两个一样的杯子”），并给出更清楚的说法。

### 功能说明

1. **双人异步信息 3D 房间**：React Three Fiber 渲染，两人分别从桌子两侧的视角观察；服务端只把目标发给 Guide（协议层面保证信息差）。
2. **两种任务**：Find（在长得一样的物品里选对那一个）与 Place（把物品放到指定位置，需讲清参照物与方向）；任务实时生成并经“可描述性”校验。
3. **个人兴趣进入关卡**：选择 Space / Animals / Food / Sports / Games，桌面就摆满对应的 Rodin 3D 物品；在 Object Studio 上传自己物品的照片即可由 Rodin 生成 3D 模型加入下一局。
4. **英语交流方式**：按住空格说话（Web Speech API 语音识别）、文字输入、快捷短语、带中文释义的短语手册；可选 WebRTC 远程语音。
5. **AI 搭档**：Nova（AI 向导）会根据你指向的物体实时纠正（“Not that one…”）；Pixel（AI 操作者）在你说得含糊时会追问“Which one?”“My left or your left?”。
6. **赛后教练**：Clarity 分数、四项技能（空间词汇、视角、澄清、速度）、逐句诊断与改写建议、可扫码带走的回放。
7. **3D 回放**：时间轴拖动，可切换 Guide 视角 / Builder 视角 / 双方全景，对话字幕同步。
8. **现场体验设计**：扫码加入（局域网二维码）、观众大屏 `/watch/房间号`（双视角并排展示）、单屏双人演示 `/demo`（含自动演示，可作备用演示）。
9. **学习进度**：本地保存每局成绩、趋势图与历史记录。
10. **Scene Agent**：批量生成新物品包（规划 → 参考图 → 人工审核 → Rodin → 优化 → 注册 → 可玩性校验）。
