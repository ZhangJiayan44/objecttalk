## APIs & models

| Service | Use | Required? |
|---|---|---|
| Hyper3D Rodin Gen-2.5 API / MCP | Image-to-3D generation (assets, Object Studio, Scene Agent) | Only for generating new objects |
| Anthropic Claude (`claude-opus-5-5` by default) | AI builder fallback interpreter, coaching rewrites, agent planner | Optional, opt-in with `ENABLE_LLM=1` |
| Browser Web Speech API | Speech-to-text and text-to-speech | Optional (typing works everywhere) |

## Design references

- UI style follows the open "playful educational platform" claymorphism template
  at uupm.cc (colour tokens, card and button recipe). All markup and code here is our own.
- Interaction pattern (2D overlays opened with keys over a 3D scene) is inspired by
  [medkit](https://github.com/bedriyan/medkit-app). **No code was copied**; medkit's
  license is proprietary.
